# Demo video script (1:45)

One take on `/demo`, driven by the right arrow key. Mei grows up on screen: she joins at 7, takes one real flight with her parent, then comes back at 15, at 20, and at graduation.

## Before recording
1. `cd frontend`, then `npm run dev`. Open `http://localhost:5173/demo` in Chrome.
2. Press **Reset trip** in the panel. This clears stamps from earlier runs and puts both phones on the first beat.
3. Press **F11** for full screen and **Ctrl+0** for 100% zoom. Turn on Do not disturb. Close terminals and any `.env` files.
4. Start the recording (Win+Alt+R for Game Bar, or Win+Shift+R for the Snipping Tool). Move the mouse off the phones.

## Controls
| Key or click | Does |
|---|---|
| Right arrow (or Next) | Next beat |
| Left arrow (or Back) | Previous beat, if you need to redo one |
| Phase name in the panel | Jumps to the start of that phase |
| Click **Press the stamp** in the phone | The stamp animation, at beat 6 only |

The phones never reload: each beat slides in like the real app. The arrow keys still work after you click inside a phone. In Teen and Campus, you can click the offer tile and **Redeem** yourself instead of using the arrow key.

## If something goes wrong
- A wrong beat: press the left arrow and say the line again. Cut the mistake in editing.
- Stamps already pressed from a rehearsal: press **Reset trip** before the next take.
- Every number in the commentary is on screen and comes from `shared/program.json`. Don't quote numbers that aren't shown.
